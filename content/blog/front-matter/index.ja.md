## フロントマッター

フロントマッターは Markdown ファイルの最上部に記述する、メタデータを設定する部分のこと。

フロントマッターは `+++` で囲まれた部分に記載します。

Zola ではセクション(ディレクトリ単位)とページ(個々の記事)で設定できるフロントマッターは異なります。

---

## セクションで設定可能なフロントマッター

[#Front matter - Section | Zola ](https://www.getzola.org/documentation/content/section/#front-matter)

[zola-daisyui-blog](https://github.com/mosaos/zola-daisyui-blog) テンプレートをそのまま利用する場合は、セクションのフロントマッターを変更する必要性は殆どないかも😅️

### プロパティ一覧

| プロパティ名                | 用途                  | 頻度 | 備考項                                                                                                                                                        |
| --------------------- | ------------------- | -- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `title`               | セクションのタイトル          | 必須 | セクションのタイトルを指定する。                                                                                                                                                   |
| `description`         | セクションの説明文           | 任意 | セクションの概要を指定する。                                                                                                                                                     |
| `draft`               | 下書き指定               | 任意 | `true` にすると下書きセクションとして扱われる。`--drafts` オプションを指定した場合に読み込まれる。デフォルトは `false`。                                                                                          |
| `sort_by`             | ページの並び順             | 任意 | セクション内のページの並び順を指定する。`date`、`update_date`、`title`、`title_bytes`、`weight`、`slug`、`none` から選択する。デフォルトは `none`。                                                        |
| `weight`              | サブセクションの並び順         | 任意 | 親セクション内でのサブセクションの表示順を指定する。数値が小さいほど優先順位が高くなる。                                                                                                                       |
| `template`            | 使用するテンプレート          | 任意 | セクションページの HTML 生成に使用するテンプレートを指定する。例：`template = "section.html"`。                                                                                                   |
| `page_template`       | 配下のページに適用するテンプレート   | 任意 | セクション配下のすべてのページ（下位セクションも含む）に適用するテンプレートを指定する。下位セクションにも設定されている場合は、ページに最も近いセクションの設定が優先される。ただし、ページ自身の `template` が設定されている場合は、そちらが優先される。                                |
| `paginate_by`         | ページネーションの件数         | 任意 | 1ページあたりに表示するページ数を指定する。`0` または未設定の場合はページネーションを行わない。                                                                                                                 |
| `paginate_path`       | ページネーションの URL パス    | 任意 | ページネーション時に使用する URL パスを指定する。ページ番号が後ろに付加される。デフォルトは `page/1`。                                                                                                         |
| `paginate_reversed`   | ページネーションの順序         | 任意 | `true` にするとページネーションの表示順を逆順にする。デフォルトは `false`。                                                                                                                      |
| `insert_anchor_links` | 見出しへのアンカーリンク追加      | 任意 | 見出しにアンカーリンクを追加する位置を指定する。`left`、`right`、`heading`、`none` から選択する。`heading` は見出し全体をアンカーリンクにする。デフォルトは `none`。テンプレートディレクトリに `anchor-link.html` を配置することで、デフォルトの表示を変更できる。 |
| `in_search_index`     | 検索インデックスへの登録制御      | 任意 | `true` にするとセクションページが検索インデックスに登録される。サイト設定の `build_search_index` が `true` であることが必要。デフォルトは `true`。                                                                    |
| `render`              | セクションページの HTML 出力制御 | 任意 | `true` にするとセクションのトップページを生成する。`false` にするとセクション自体をコンテンツの整理用として利用できる。デフォルトは `true`。                                                                                  |
| `redirect_to`         | リダイレクト先             | 任意 | セクションの URL にアクセスした際の転送先を指定する。例：`redirect_to = "documentation/content/overview"`。`render = false` と組み合わせ、セクションのトップページを生成せずに別ページへ転送したい場合などに利用できる。                    |
| `transparent`         | 親セクションへのページ引き継ぎ     | 任意 | `true` にすると、このセクションのページを親セクションのページ一覧に引き継ぐ。年別セクションなど、親セクションのページ一覧を分割したくない場合に利用できる。デフォルトは `false`。                                                                   |
| `aliases`             | 旧 URL の転送先設定        | 任意 | URL を変更した際などに、旧 URL から新 URL へのリダイレクトを設定する。URL ではなくパスの配列で指定する。例：`aliases = ["old-section"]`。                                                                        |
| `generate_feeds`      | セクションフィードの生成        | 任意 | `true` にするとセクションのルートパスにフィードファイルを生成する。サイト全体のフィード設定とは独立している。このセクション自身の投稿のみが対象となり、サブセクションの投稿は含まれない。デフォルトは `false`。                                                    |
| `hidden`              | セクションの一覧等への掲載制御     | 任意 | `true` にするとセクション自体は生成されるが、親セクションのサブセクション一覧、サイトマップ、フィード、検索インデックスなどには含まれなくなる。デフォルトは `false`。配下のページにもデフォルトで適用されるが、各ページで `hidden` を設定して個別に変更できる。                       |
| `[extra]`             | 独自データの設定            | 任意 | サイト独自の情報を追加するための領域。テンプレートから `section.extra` などで参照できる。                                                                                                              |

### 注意点

後述するページ用のフロントマッターと似ている項目もあるが、セクション特有の設定も多い。

#### `render` と `redirect_to` の違い

| 設定               | 動作                            |
| ---------------- | ----------------------------- |
| `render = true`  | セクションのトップページを生成する。            |
| `render = false` | セクションのトップページを生成しない。           |
| `redirect_to`    | セクションの URL にアクセスした際の転送先を指定する。 |

セクションをコンテンツの整理用としてだけ利用し、トップページを表示させたくない場合に役立つ。

#### `transparent` の用途

例えば、次のようなディレクトリ構成を考える。

```
content/
└── posts/
    ├── _index.md
    ├── 2025/
    │   ├── _index.md
    │   └── article1.md
    └── 2026/
        ├── _index.md
        └── article2.md
```

通常は `2025` と `2026` の各セクションでページが分かれるが、`transparent = true` にすると、それらのページを親の `posts` セクションに引き継げる。

年別にコンテンツを整理しつつ、親セクションではまとめて一覧表示したい場合に便利。

#### `page_template` と `template` の違い

- `template`：そのセクション自身のページを生成する際に使用するテンプレート。
- `page_template`：そのセクション配下にある個々のページを生成する際に使用するテンプレート。

なお、ページ自身に `template` が指定されていれば、そちらが優先される。

#### `hidden` の適用範囲

Page Front Matter の `hidden` と異なり、Section Front Matter の `hidden` は配下のページにも影響する。  
ただし、配下のページで個別に `hidden` を設定すれば、その設定で上書きできる。

## ページで設定可能なフロントマッター

[#Front matter - Page | Zola ](https://www.getzola.org/documentation/content/page/#front-matter)

### プロパティ一覧

上記リンクに記載があるのは以下


| プロパティ名             | 用途             | 頻度 | 備考項                                                                                                                                        |
| ------------------ | -------------- | -- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`            | ページのタイトル       | 必須 | ページのタイトルを指定する。                                                                                                                                     |
| `description`      | ページの説明文        | 任意 | ページの概要を指定する。検索エンジン向けの説明文などにも利用できる。                                                                                                                 |
| `date`             | ページの作成日        | 任意 | `YYYY-MM-DD` または RFC3339 形式で指定する。例：`date = 2026-11-08`。ファイル名に設定された日付より優先される。セクションの `sort_by` が `date` の場合、未設定のページは出力されない。                          |
| `updated`          | ページの最終更新日      | 任意 | `date` と異なる場合に指定する。`date` と同じ形式で指定する。                                                                                                              |
| `weight`           | ページの並び順        | 任意 | 数値で指定する。セクションの `sort_by` が `weight` の場合、未設定のページは出力されない。                                                                                            |
| `draft`            | 下書き指定          | 任意 | `true` にすると下書きページとして扱われる。通常のビルド・プレビューでは読み込まれず、`--drafts` オプションを指定した場合に読み込まれる。デフォルトは `false`。                                                       |
| `render`           | ページの HTML 出力制御 | 任意 | `false` にすると、そのページ専用のディレクトリや `index.html` を生成しない。デフォルトは `true`。                                                                                    |
| `slug`             | URL の末尾部分      | 任意 | ファイル名の代わりに URL の末尾部分を指定する。親セクションのパスは引き続き使用される。                                                                                                     |
| `path`             | ページの URL パス    | 任意 | ページの URL パス全体を指定する。`slug` やファイル名より優先され、親セクションのパスは使用されない。空文字列は指定できない。先頭の `/` は不要（指定しても削除される）。                                                       |
| `aliases`          | 旧 URL の転送先設定   | 任意 | URL を変更した際などに、旧 URL から新 URL へのリダイレクトを設定する。URL ではなくパスの配列で指定する。例：`aliases = ["old-page"]`。                                                           |
| `authors`          | ページの著者         | 任意 | 著者名の配列で指定する。サイトフィードが有効な場合、デフォルトのフィードテンプレートでは最初の著者がページの著者として使用される。                                                                                  |
| `in_search_index`  | 検索インデックスへの登録制御 | 任意 | `false` にすると検索インデックスへの登録対象外になる。サイト設定の `build_search_index` が `true` であることが必要。また、親セクションで `in_search_index = false` が設定されている場合は登録されない。デフォルトは `true`。 |
| `include_in_feeds` | フィードへの掲載制御     | 任意 | `false` にすると、サイト・セクション・タクソノミーのすべてのフィードから除外される。デフォルトは `true`。                                                                                       |
| `template`         | 使用するテンプレート     | 任意 | ページの HTML を生成する際に使用するテンプレートを指定する。例：`template = "page.html"`。                                                                                       |
| `hidden`           | ページ一覧などへの掲載制御  | 任意 | `true` にするとページ自体は生成されるが、セクションのページ一覧、サイトマップ、検索インデックス、フィードなどには含まれなくなる。デフォルトは `false`。                                                                |
| `[taxonomies]`     | タクソノミーの設定      | 任意 | タグやカテゴリなどを指定する。キーには `zola.toml` で定義したタクソノミー名を使用し、値には文字列の配列を指定する。例：`tags = ["rust", "web"]`。                                                        |
| `[extra]`          | 独自データの設定       | 任意 | サイト独自の情報を追加するための領域。テンプレートから `page.extra` などで参照できる。                                                                                                 |


以下ページでのフロントマッターの例を示す。  
※ [zola-daisyui-blog](https://github.com/mosaos/zola-daisyui-blog) テンプレートでよく利用する例

```toml
+++
title = "タイトル"
description = "記事の説明"
date = 2026-11-01
updated = 2026-11-05

[taxonomies]
tags = ["Zola"]
authors = ["mosaos"]

[extra]
thumbnail = "zola-daisyui-blog.webp"
show_thumbnail = true
+++
```

### 注意点

#### `render` と `hidden` の違い  

| プロパティ            | ページの HTML 生成 | ページ一覧・サイトマップ等 |
| ---------------- | ------------ | ------------- |
| `render = false` | 生成しない        | 対象外           |  
| `hidden = true`  | 生成する         | 対象外           |  

`hidden` は、ページ自体にはアクセスできるが、通常の一覧などには表示させたくない場合に利用する。

#### `slug` と `path` の違い

- `slug`：親セクションのパスを維持したまま、URL の末尾部分を変更する。
- `path`：親セクションのパスに関係なく、URL パス全体を指定する。

#### `date` と `updated` の違い

- `date`：記事の作成日。
- `updated`：記事の最終更新日。

日付は引用符で囲まず、ゼロ埋めした `YYYY-MM-DD` 形式で記述することを推奨する。

#### `in_search_index` と `hidden` の違い

`in_search_index = false` は検索対象から除外するだけなのに対し、`hidden = true` は検索だけでなく、ページ一覧やサイトマップ、フィードなどからも除外する。  
なお、`title` は基本項目だが、厳密にはすべてのページで必須というわけではない。

### [taxonomies]

フロントマッターでは `[taxonomies]`、`[extra]` テーブルも設定できる。 
> ※ toml では `[`、`]` で囲まれたものはテーブルと呼ぶらしい。  

`zola.toml` ( 旧 config.toml ) で `taxonomies` を設定する事で利用する事ができるようになる。

[zola-daisyui-blog](https://github.com/mosaos/zola-daisyui-blog) テンプレートの `zola.toml` では以下を設定してある。

```toml
[languages.en]
...
taxonomies = [
    { name = "tags" },
    { name = "authors" },
]

[languages.ja]
...
taxonomies = [
    { name = "tags" },
    { name = "authors" },
]
```

つまり、`tags` と `authors` という2種類の taxonomy が利用できるようになっている。  
※ `categories` を追加するなどしても構わない。

フロントマッターでは以下のような設定を行う。

```toml
[taxonomies]
tags = ["Zola"]
authors = ["mosaos"]
```

これによって、Zola 組み込みのタクソノミー機能で、コンテンツを分類できる。  

[zola-daisyui-blog](https://github.com/mosaos/zola-daisyui-blog) テンプレートではサイドバーにタグ (tags) と著者 (authors) 用のリンクを用意してある。

### [extra]

`[extra]` テーブルでは利用者が独自の設定を追加することが可能になっている。  
[zola-daisyui-blog](https://github.com/mosaos/zola-daisyui-blog) テンプレートでは以下を利用できるようになっている。

- **thumbnail**  
ページのサムネイル画像を指定する。テンプレートが、フォルダ単位で記事を作成 ( 記事でリンクする画像などのアセットをまとめる構成 ) する構成を想定しているので、サムネイル画像も記事と同じフォルダに置いてそれを指定するのが判りやすいと思う。
サムネイル画像は `blog-list.html`, `works-list.html`, `latest-articles.html` 等の記事を一覧する画面でのサムネイル表示で使われる。  
また `head-ogp.html` で出力している OGP 用の画像にも指定している。
- **show_thumbnail**  
`true` にした場合、ページの最上部にサムネイルを表示する。表示される画像は `thumbnail` で設定した画像。
- **slideshow**  
`true` にした場合、ページのフォルダに含まれる画像をスライドショー表示するようにしている ( `page.html` )。

```toml
[extra]
thumbnail = "nudibranch-01.jpg"
slideshow = true
```
